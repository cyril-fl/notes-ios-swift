# Notes iOS App

A simple iOS note-taking app built with Swift. Ideal for learning Swift app architecture and iOS development fundamentals.
This app allows users to organize their notes into folders, and provides full CRUD functionality (Features include creating, editing, and deleting notes).

## Features

- Create, read, update, and delete notes
- Organize notes into folders
- Local data persistence using SwiftData
- Clean and user-friendly interface

## Minimum Requirements

- iOS 18.0
- Xcode 15 or later

## Technologies Used

- Swift
- SwiftData

## Installation

To run the app locally:

1. Clone the repository:
   ```bash
   git clone git@github.com:your-username/notes-ios-swift.git
   ```
2. Open the project in Xcode:
   ```bash
   open Notes.xcodeproj
   ```
3. Run the app on a simulator or physical device with iOS 17.6 or later.
